# Copy review

Check the edited text itself, not a promise that the rules were followed.

1. Preserve the intended meaning, specific facts, and recognizable voice.
2. Remove generic filler without flattening character or stripping necessary nuance.
3. Ground each product claim in available evidence; flag consequential missing facts.
4. Replace empty rhetoric, vague attribution, synonym cycling, and artificial endings.
5. Use consistent names, natural sentence progression, and functional formatting.
6. Keep code identifiers, quoted material, and required technical/legal terms intact.
7. Distinguish simulated, pending, verified, accepted, and deployed behavior.
8. Make controls and questions explain the action or decision clearly.
9. Preserve accessibility labels and useful error guidance.
10. Return the requested artifact without adding an editing report to visible UI.

Fix failed checks before delivery. Report unavailable evidence instead of inventing it.
