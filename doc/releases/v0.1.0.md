# HandoffCheck v0.1.0 Windows pilot

Product managers submit feature requests through Google Forms or HandoffCheck. Authors resolve clarification questions, assign two distinct leads, and obtain approval for the same revision. Approved briefs can be downloaded as Markdown and exported to a private Google Doc by the owner-operated Apps Script connector.

This release adds a Windows x64 installer. The desktop app connects to the hosted workspace and opens Google sign-in in the user's system browser. Existing employee invitations and approval rules apply.

The installer is unsigned. Windows may show an unknown-publisher warning. The release includes a SHA-256 checksum for the installer. Internet access is required; there is no offline workspace or automatic desktop update mechanism. Reinstall a newer release to update the desktop runtime.

Google Form-to-draft and approved-Doc export acceptance checks remain part of the pilot. Setup and backend asset binding are verified; this release does not claim those complete live workflows have passed.
